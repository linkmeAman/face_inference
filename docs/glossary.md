# Glossary of Terms

Plain-English definitions for terms used across the `face_inference` documentation and user interface.

1. **API token**  
   A private secret password made of random characters that grants administrative control over the face service. Anyone who possesses your API token has full access to your collections, configuration, and data, so never share it publicly.

2. **Port**  
   A numbered communication channel on your computer (such as `6122`) that allows software programs to talk to each other over a network. The face service listens on port 6122 so your browser can connect to its local web interface and API.

3. **Localhost (127.0.0.1)**  
   A special network address that means "this exact computer you are currently using." Connecting to `http://127.0.0.1:6122` ensures all network traffic stays entirely inside your physical machine without traveling across the internet.

4. **Collection**  
   A named grouping or folder used to organize people and their enrolled facial templates. For example, you can create separate collections named `team-one` or `visitors`.

5. **Enrollment**  
   The process of capturing a person's face using a webcam, computing a mathematical representation, and saving it into a collection. Once enrolled, the person can be recognized in future scans.

6. **Recognition**  
   The process of scanning an unknown face in front of the camera and comparing it against all enrolled templates in a collection. The system identifies the closest matching person above a confidence threshold.

7. **Template (Embedding)**  
   A list of 128 mathematical numbers representing facial features extracted by the AI model. The system saves only these encrypted numbers in its database and never stores raw photographic images or video recordings of faces.

8. **Consent**  
   Explicit permission granted by an individual permitting their facial measurements to be captured and stored. The software requires a confirmed consent record before saving any facial reference into the system.

9. **Session token**  
   A short-lived, restricted credential generated by your backend server that expires after a few minutes (such as 300 seconds) and permits only one specific action, like recognizing a face. Unlike the main API token, session tokens are safe to embed in public web pages.

10. **config.json**  
    A private settings file created in your data directory that stores server configuration, your administrative API token, and the master database encryption key. If this file is lost or deleted, existing enrolled faces cannot be decrypted.

11. **Data directory**  
    The folder on your hard drive where `config.json` and the encrypted database (`faces.sqlite3`) reside. It defaults to your operating system's standard application data directory and can be customized using the `FACE_INFERENCE_HOME` environment variable.

12. **Virtual environment (venv)**  
    An isolated directory containing a dedicated copy of Python and installed packages for a specific project. It prevents the project's dependencies from interfering with other software installed on your system.

13. **CORS / Origin**  
    Cross-Origin Resource Sharing (CORS) is a browser security safeguard that prevents websites on one domain from making unauthorized background requests to another domain or local server. The face service blocks browser connections unless the calling website's address (origin) is explicitly allowlisted in `allowed_origins`.

14. **Liveness**  
    A security technique used to verify that a face presenting to a camera belongs to a living person rather than a printed photograph or digital screen replay. This project does not provide liveness detection and cannot distinguish a real person from a picture.

15. **Evaluation mode**  
    The default operating mode of the service where matching results are reported as suggestions for human review rather than automatic authoritative decisions. It enables testing, tuning, and accuracy verification before operational deployment.

16. **Idempotency key**  
    A unique tracking identifier (such as a UUID or unique label) sent alongside a request to ensure that network retries never accidentally execute the same action twice or create duplicate entries.

17. **Docker image and container**  
    A pre-packaged software bundle containing the application and all necessary system dependencies (an image), and the live running instance of that image (a container). It provides a way to run the service without manually managing Python packages on your computer.

18. **Docker volume**  
    A dedicated storage space managed by Docker that keeps your database and configuration safe on your computer even if the container itself is stopped, updated, or removed.

19. **YuNet**  
    A compact, high-efficiency neural network model that runs directly in your web browser to identify the coordinates and boundaries of human faces within video frames.

20. **SFace**  
    A neural network model that converts a cropped face image into a 128-dimensional mathematical template used for identity matching and comparison.

21. **WebAssembly (WASM)**  
    A high-performance technology that allows complex programs, including AI neural network runtimes, to execute directly inside standard web browsers at near-native speed.

22. **Key rotation**  
    A security procedure that generates a new master encryption key and re-encrypts all stored database templates with the new key without losing existing enrollments or audit logs.

23. **Retention period**  
    A configurable duration (defaulting to 30 days) after which stored biometric templates and event logs are automatically scheduled for permanent erasure from the database.
