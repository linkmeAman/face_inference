# Face capture and attendance

Open Attendance, then select your branch, batch, date and session. Your usual Attendance permission is sufficient. Use the existing invoice consent process; only point the camera at members whose required authorization has been obtained.

1. **Enroll Face:** Use the child's own row. Position their face inside the circle. Capture is automatic; the green ring shows accepted observations. “Face captured. Attendance setup is pending” means the face is stored but automatic biometric attendance is not approved yet. A possible duplicate is not a successful enrollment.
2. **Scan Arrivals:** Show one consenting child at a time. Names are suggestions, and attendance rows stay unchanged. The camera continues scanning.
3. **Finish Scanning:** The camera stops and the review list opens.
4. **Review:** Independently check each child's identity. Select only verified children; remove incorrect suggestions. Every suggestion starts unchecked. Use Back to Scanning if necessary.
5. **Confirm Attendance:** Saves only the selected members. Wait for “Attendance confirmed” and the updated rows. If some members fail, review those results and retry only as needed. For a lost connection, use Retry to check the original request.

Manual attendance remains available. Closing or changing sessions can discard unsaved suggestions; heed the warning. Face enrollment does not need repeating for each session. Camera unavailable? Check browser permissions and tap Retry. Do not treat an unvalidated suggestion as proof of identity.

For a class with approved automatic attendance, Scan Arrivals marks recognized
members immediately and keeps scanning. There is no review or confirmation button
in that mode. Unrecognized faces remain unmarked. Closing the camera does not mark
absences; class cutoff rules apply separately. Enrollment says Enrolled only after
activation. Other classes currently use the SHADOW review instructions above.
